- [L-210f51f9] A redacted `.patch` no longer applied -> collapsing a user path to `$PROJECT_ROOT/...` changed the leading component count so `patch -pN` stripped the wrong directories -> `anonymize(..., preserve_structure=True)` for `.patch`/`.diff` (STRUCTURED_SUFFIXES) replaces only the username segment; verify line count, `@@` count and `/` per header unchanged (2026-07-30)
